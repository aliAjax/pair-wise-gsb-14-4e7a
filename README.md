# 区域夜间换价 · 互相牵制下发台账

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

总部基准、油枪租约、站端回执三方分账，互相牵制：

1. **基准 → 租约**：基准更新后，在途租约中未签名油枪立即失效，并自动生成新基准租约；已签名油枪沿用原基准。
2. **回执合并**：断网回执按租约编号 + 枪号合并——内容一致拦截重复盖章，同枪冲突两边留档交区域复核。
3. **签名重试**：签名失败后必须从完整租约快照重试，不允许残缺补签。
4. **晚改牵制**：主管晚改可把已签场次带回待执行，但已有盖章回执的场次被回执牵制。
5. **越权拦截**：站端账号仅可提交本组材料，跨组提交一律拦截留痕；审计页逐枪显示沿用或失效的基准。

数据保存在浏览器 localStorage，右上角可切换账号角色（总部 / 区域主管 / 站组账号）、一键重置演示数据。
